# NØVA – Objects for Everyday Living

NØVA is a modern e-commerce website designed to provide a simple, engaging, and convenient online shopping experience. The platform focuses on lifestyle products, technology accessories, audio equipment, and everyday essentials.

The goal behind NØVA is to create a clean and intuitive shopping experience through thoughtful design, smooth animations, and interactive features that make browsing and discovering products enjoyable.

## About the Project

NØVA explores how modern frontend technologies can be used to build a functional and visually appealing online store. The website features a carefully designed interface, organized product displays, interactive shopping elements, and smooth transitions.

The project is currently focused on the frontend, with product information and shopping interactions managed on the client side.

## Features

Product Catalogue

Products are displayed in an organized catalogue with dedicated categories and collections. Users can browse available products, search for specific items, and filter products based on their preferences.

Shopping Cart

Users can add products to their cart, adjust quantities, remove items, and view automatically calculated subtotals.

Wishlist

Users can save products they are interested in and easily access them later.

Search and Filtering

The website provides product search and filtering functionality to make finding specific items easier.

Animations and Interactions

Smooth transitions, subtle animations, and interactive elements help create a polished browsing experience.

Responsive Design

The website is designed to work across desktop computers, tablets, and mobile devices.

## Technologies Used

React: Used to build the user interface and manage reusable components.

Vite: Provides the development environment and production build process.

Tailwind CSS: Used for styling and responsive layouts.

Framer Motion: Used for interface animations and transitions.

GSAP: Handles advanced animations and interactive effects.

Lucide React: Provides icons used throughout the interface.

## Getting Started

To run the project locally, make sure you have Node.js and npm installed.

1. Clone the repository:

   git clone https://github.com/alfreddameteykwami/nova-store.git

2. Navigate to the project directory:

   cd nova-store

3. Install the required dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open the local URL displayed in your terminal. By default:

   http://localhost:5173

## Available Scripts

npm run dev

Starts the local development server.

npm run build

Creates an optimized production build.

npm run preview

Allows you to preview the production build locally.

## Project Status

NØVA is currently under development as a frontend e-commerce project. The product catalogue, shopping cart, wishlist, and other shopping interactions are handled on the client side.

Backend services, database integration, user authentication, order management, and payment processing have not yet been implemented.

## Future Improvements

Future development may include backend integration, persistent shopping carts, user accounts, product reviews, order tracking, payment processing, and an administration dashboard for managing products and orders.
